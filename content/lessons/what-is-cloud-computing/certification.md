## AWS Certified Cloud Practitioner (CLF-C02)

This lesson is core material for **Domain 1: Cloud Concepts**, which is **24%** of the scored exam content. It falls under **task statement 1.1: define the benefits of the AWS Cloud**.

Expect questions like:
- Which benefit lets a company avoid buying servers for its peak season? → *Stop guessing capacity* / elasticity.
- A startup wants to avoid large up-front investment. Which advantage applies? → *Trade fixed expense for variable expense.*
- A company wants to serve users on another continent with low latency without building a data centre. → *Go global in minutes.*

**Exam technique:** CLF-C02 questions are usually short scenarios. Match the scenario's *pain* (up-front cost, unpredictable traffic, slow hardware purchase, global reach) to one of the six advantages. Learn the six by their exact wording.

The CLF-C02 domains are:

| Domain | Weight |
|---|---|
| 1. Cloud Concepts | 24% |
| 2. Security and Compliance | 30% |
| 3. Cloud Technology and Services | 34% |
| 4. Billing, Pricing, and Support | 12% |

## Associate level and beyond

Solutions Architect – Associate (SAA-C03) and the other associate exams don't ask you to define cloud computing directly. They **assume** you understand it. Their scenarios constantly test elasticity, high availability and pay-per-use cost thinking, which all build on this lesson.

> Always check the current official exam guide on aws.amazon.com/certification before you book an exam. Domains and weights change between exam versions.
